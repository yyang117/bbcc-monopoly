# BBCC Monopoly — 全链路大富翁

> 供应链技术比赛互动小游戏 🎲

一款以京东物流 BBCC 仓网全链路为主题的网页大富翁游戏。玩家扮演供应链总监，从签约入驻到入仓、出库、结算，体验真实供应链运营中的每一个关键节点。

## 🎮 游戏规则

- 掷骰子沿流程前进，每个节点触发不同的供应链事件
- 管理好你的 **资金 (Cash, 初始20万)**、**血压 (Sanity, 初始100)**、**工厂/B仓/C仓库存** 和 **现货率**
- 血压归零、超过150、或低于70 → Game Over
- 资金归零 → Game Over
- 到达「支付费用」节点即可通关，或触发隐藏关卡获得额外分数

## 🗺️ 18个流程节点

1. 物流维护BC仓网覆盖中
2. 确认费率和折扣
3. 确认入仓方案
4. 签订运输协议
5. 物流数据创建中
6. 京麦权限开通
7. 算法C仓选品
8. 开始销量预测
9. 自动补货配置中
10. 需求单来了！
11. 拆ASN预约送仓
12. B仓收货中
13. B仓库存更新
14. BC调拨已发起
15. C仓库存更新
16. 查询账单
17. 支付费用
18. 🔒 清理滞销（隐藏关卡）

## 🛠️ 技术栈

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Vercel** 部署

## 📦 本地开发

```bash
npm install
npm run dev
```

访问 http://localhost:3000

## 🚀 部署

已部署至 Vercel：https://bbcc-monopoly.vercel.app

```bash
vercel --prod
```

## 🧩 架构

```
src/
├── app/
│   ├── globals.css      — 暗色Hello Kitty主题样式
│   ├── layout.tsx       — 根布局
│   └── page.tsx         — 主游戏页面（棋盘+仪表盘+骰子+弹窗+结算）
└── lib/
    ├── gameTypes.ts     — 类型定义 + 玩家初始状态
    ├── board.ts         — 18格循环棋盘定义
    └── events.ts        — triggerLLMEvent() + 供应链事件逻辑
```

## 📊 排名系统

通关后综合评分 = 剩余资金/10000 + 血压×100 - 掷骰次数×50

| 等级 | 分数 | 超越玩家 |
|------|------|----------|
| S | ≥8000 | 99% |
| A | ≥6000 | 90% |
| B | ≥4000 | 70% |
| C | ≥2000 | 40% |
| D | <2000 | 10% |
